# Circle Money — システム構造と使い方

Circle Moneyの構成と操作を説明する、日本語の公開HTMLガイドです。

**[ガイドを開く](https://degawa1013-gif.github.io/circle-money-guide/)**

## 掲載内容

- 選択・拡大・ドラッグできる構成図とノードの詳細
- Discord入力・会計サイト・端末内OCRの経路切替とステップ再生
- 架空データで試せる確認・登録・中止の操作デモ
- 全8コマンド、レシートの扱い、データ保存場所、運用・トラブル対応

HTML / CSS / JavaScriptのみ。ビルドやライブラリのインストールは不要です。
`index.html`をブラウザーで開くか、フォルダで `python3 -m http.server 4173` を実行してください。
GitHub Pagesは公開ブランチのルートを配信します。

## 公開範囲

このリポジトリには説明ページのコードだけを収録しています。
本番会計アプリやBotのソース、実際の会計明細、写真、秘密鍵、パスワード、個人用の接続URLやDiscord識別子は含めません。
操作デモはメモリー内で完結し、会計サービスへの通信・登録・永続保存は行いません。
解析タグ、外部フォント、外部スクリプトはありません。GitHubによる通常のアクセス情報処理は発生します。

## 構成の要点

Discord操作 → 署名・担当者・指定先を検証する受付 → 暗号化した処理待ちデータ → Google Apps Scriptによる毎分の取得 → 非公開Googleシート。
受付はSites上のCloudflare Workers、処理待ちはD1を使用します。Discord側はEd25519署名、Google側との連携はHMAC署名を検証します。
結果は受付からDiscordの本人限定返信へ反映します。
会計サイトは共有された会計用パスワードで認証し、Google側の処理を通じてシートを操作します。パスワードを知るメンバーは閲覧・登録・取消ができます。シート自体は非公開です。
写真は会計サイトの端末内で読み取り、確認済みの項目のみ登録します。

記述は2026年10月6日に確認した実装に基づきます。現在のBot操作はアプリ所有者本人と指定サーバー・チャンネルに限定されています。
